-Title :
Password Strength & Breach Checker

-Description :
Password Strength & Breach Checker is a Python-based desktop application that helps users evaluate the security of their passwords. It analyzes password strength based on length, character variety, common patterns, and checks whether the password has appeared in known data breaches using the Have I Been Pwned API (with k-anonymity for privacy). The tool also includes a built-in strong password generator.
This project was developed as part of a Cybersecurity Internship to demonstrate practical understanding of password security, secure coding practices, and basic GUI development.

-Features : 
Real-time Password Strength Analysis
Strength Rating (Weak, Medium, Strong, Very Strong)
Visual Strength Progress Bar
Detection of Common & Weak Passwords
Data Breach Check using Have I Been Pwned (k-anonymity)
Built-in Strong Password Generator
Show / Hide Password option
Clean and Modern Dark-Themed GUI
Detailed Security Report with Suggestions

-Technologies Used :
Python 3
Tkinter (GUI Framework)
ttk (Themed Widgets)
Requests (API Communication)
Hashlib (SHA-1 Hashing)
Regular Expressions (re)
Have I Been Pwned API

-Installation :
Clone or download the project
Install required packages
Make sure you have Python 3 installed

-Usage : 
Run the application
     python3 PasswordChecker.py
     
Enter a password in the input field.
Click Analyze Password to check strength and breach status.
Use the Password Generator to create strong passwords.
Toggle Show to reveal or hide the password.
